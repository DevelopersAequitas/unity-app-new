  3. **Leadership Selection & Scoped Leadership Surface ([routes/leadership.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/routes/leadership.php)):** Mounted at `/api/v1/leadership`. Protected by `['auth:sanctum', 'ensure.ded.api']` ([EnsureDedApiAccess.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Http/Middleware/EnsureDedApiAccess.php) — requires `AdminUser` with `ded` role + assigned district).
  5. **Admin API & Blade Web Surface (`routes/api.php:701–1305`, `routes/admin_store.php`, `routes/web.php`):** **CRITICAL `P0` PRIVILEGE ESCALATION:** `/api/v1/admin/*` in `routes/api.php:701–1305` is mounted inside `['auth:sanctum', 'unity.user']` **without any admin role middleware**, allowing any mobile peer token (including the Leader App's direct `/admin/*` calls in [api_endpoints.dart](file:///D:/office%20project/LeaderApp-Fornt-end-/lib/core/constants/api_endpoints.dart#L58-L83)) to hit admin endpoints! Additionally, `/api/v1/rbac/*` and `/api/v1/admin/rbac/*` (`routes/api.php:312–380`) are **completely unauthenticated**.
