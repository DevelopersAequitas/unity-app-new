## 1. Non-Negotiable Platform Calculation Invariants

Every SQL query, Eloquent service, BLoC state, PDF generator, and CSV export across the Peers Global Leadership ecosystem MUST obey four canonical invariants:

1. **Invariant 1 — All-Circles Deduplicated Peers Rule:**
   - Whenever `"All Circles"` (or Territory / Industry / Country / Global scope) is selected, Peer headcounts and rosters MUST count **distinct eligible Peers (`COUNT(DISTINCT users.id)`)** within the caller's authorized scope, **never** `SUM(circle_peers_count)` across Circles.
   - Multi-circle Peers (`multi_circle_peer`) appear **once** in person-level rosters with a `memberships[]` array (`[{circle_id, circle_name, role, category, status}]`), reporting both `meta.unique_peers` and `meta.qualifying_memberships`.
2. **Invariant 2 — Authoritative Finance & `—` (`Unavailable`) Rule:**
   - Platform/Circle Revenue, Collections, Dues, and Commissions MUST come **exclusively** from authoritative financial tables (`payments` with verified paid status + explicit `circle_id`, `circle_subscriptions`, `finance_ledger_transactions`, `finance_wallets`, `finance_leader_bonus_awards`).
   - **Strictly Prohibited:** `overall_revenue = $dealsSum * 0.05` (`[LeaderDashboardService.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Leader/Services/LeaderDashboardService.php#L733)`), `(circle_price ?? 120000) * peers` (`[LeaderTeamsService.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Leader/Services/LeaderTeamsService.php#L478)`), `orWhereHas('user.circleMembers')` cross-circle payment bleed (`[LeaderFinanceService.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Leader/Services/LeaderFinanceService.php#L77)`), and substituting Business Deal value for Revenue.
   - Whenever an authoritative numeric value is unavailable (`null`), APIs MUST return `null` (with `{amount: number|null, currency: "INR"}`) and the UI MUST display **`—` (`Unavailable`)** — preserving `₹0` strictly for verified numeric zero.
3. **Invariant 3 — Zero Synthetic / Fabricated Fallback Numbers:**
   - Remove every hardcoded multiplier, fake percentage split (`60%/25%/15%` Asks, `70%/30%` Certifications), hardcoded literal (`circulars = 5`, `activeTenures ?? 42`, `attendance_percentage ?? 94.5`, `'₹18.5L'`, `'₹24.0L'`), and fictional leaderboard/notification persona (`Siddharth Verma`, `Ananya Roy`, `Vikram Mehta`). Empty datasets return `0` or `[]` honestly.
4. **Invariant 4 — Server-Side Scope Intersection & Capability Enforcement:**
   - Every read, download, and export endpoint MUST intersect client filter parameters (`?circle_id`, `?district_id`, `?industry_id`, `?scope`) with the caller's server-resolved scope (`403` on unauthorized scope) and enforce `leader.can:<capability>` (`access_finance` on all revenue/payment fields!).
