## 1. Input Architecture & Summary Classification

- **FACT:** Across the 35 activities:
  - **25 Activities** expose rich multi-field interactive forms (`#1`–`#21`, `#24`, `#30`–`#32`, `#34`, plus manual submission paths in `#22` and `#23`).
  - **4 Activities** use single-action / picker / toggle mutations (`#25` Admin Deactivate modal / Member Post Report sheet, `#26` Video Picker + `intro_video_id`, `#27` Phonebook Multi-Select + Introducer Claim, `#29` Block User confirmation).
  - **4 Activities** are **100% System-Derived / Read-Only** (`#28 Badges Earned`, `#33 Who Viewed My Profile`, `#35 Last Month Activity Summary` — note `#35` has an optional companion `GratitudeScriptScreen` reflection helper).
- **FACT (Validation Discrepancies Between Workbook & Code):**
  1. **#1 Business Deals:** Workbook lists `Proof receipt attachment`; [StoreBusinessDealRequest.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Http/Requests/Activity/StoreBusinessDealRequest.php#L16-L24) accepts **no media/file field** (`// Right now business deals have no media` in [BusinessDealController.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Http/Controllers/Api/BusinessDealController.php#L50)).
  2. **#3 Normal Referrals:** Workbook lists `Inside / Outside` for Referral Type and `Warm / Hot / Super Hot` for Hotness; [StoreReferralRequest.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Http/Requests/Activity/StoreReferralRequest.php#L93-L112) validates `referral_type` against 7 B2B/customer enums (`customer_referral`, `b2b_referral`, `b2g_referral`, `collaborative_projects`, `referral_partnerships`, `vendor_referrals`, `others`) and `hot_value` as integer `1..5`. Meanwhile, Leader App [LeaderCreateReferralRequest.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Leader/Requests/LeaderCreateReferralRequest.php#L18-L28) uses completely different field names (`to_peer_id`, `prospect_name`, `prospect_company`, `estimated_deal_value`, `notes`)!
  3. **#8 Testimonials:** Workbook specifies `1-to-5 Star rating` and `min 20 chars`; [StoreTestimonialRequest.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Http/Requests/Activity/StoreTestimonialRequest.php#L16-L22) has **neither** `rating` nor `min:20` (`content` is `required|string`).
  4. **#9 & #10 Certifications:** Workbook describes document uploads (`turnover verification`, `incorporation documents`, `milestone checklist`); [SubmitEntrepreneurCertificationRequest.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Http/Requests/Forms/SubmitEntrepreneurCertificationRequest.php#L35-L46) and `SubmitLeadershipCertificationRequest` actually validate **4 identity fields + 25 mandatory multiple-choice quiz fields (`QUIZ_FIELDS`)**.
  5. **#15 Become a Mentor:** Workbook lists `Mentorship domains`, `Years of experience`, `Available slots`, `Bio`; [SubmitBecomeMentorRequest.php](file:///c:/Users/malic/OneDrive/Documents/GitHub/unity-app-new/app/Http/Requests/Forms/SubmitBecomeMentorRequest.php#L28-L35) only accepts 6 basic contact fields (`first_name`, `last_name`, `email`, `phone`, `city`, `linkedin_profile`).
