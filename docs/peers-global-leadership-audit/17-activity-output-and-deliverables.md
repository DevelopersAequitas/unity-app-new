# 17 — Activity Outputs, Visual Creatives & Deliverables Reference

> **Document Scope:** Comprehensive mapping of all **11 Output & Deliverable Categories** across all **35 Platform Activities** — explicitly separating **Implemented in Production Code (`FACT`)** from **Described Only in Workbook (`WORKBOOK REQUIREMENT` / `NOT IMPLEMENTED`)**.
>
> **The 11 Output Categories:**
> 1. **Screen Output** (Immediate detail/confirmation UI)
> 2. **History / List Output** (Member App, Leader App & Admin Web lists)
> 3. **Visual / Milestone Cards** (`WelcomeCreativeService`, `IntroductionCreativeService`, `LifeImpactCreativeGenerator`, `activity_creatives`, Canva-style React Admin studio)
> 4. **Certificates** (`CertificateGeneratorService` DomPDF, Global Peer Certificate)
> 5. **Reports** (`LeaderReportPdfGenerator` DomPDF, Admin/Leader CSV exports, DED reports)
> 6. **Badges & Honours** (`MilestoneBadgeService`, `ContributionMilestoneResolver`)
> 7. **QR Codes** (`endroid/qr-code` event tickets, profile QR)
> 8. **PDFs & Tax Invoices** (`ZohoInvoiceDocument`, event invoices, circle directory PDF)
> 9. **Notifications** (FCM HTTP v1 Push, Dual-table `app_notifications` + `notifications`, Meta WhatsApp Cloud API v22.0 / Webhook, 42 Mailables)
> 10. **Metrics & Counters** (`users` cached columns + dynamic KPIs + Leaderboards)
> 11. **Shareable Assets** (Timeline auto-posts, WhatsApp/system share intents, public links)
>
